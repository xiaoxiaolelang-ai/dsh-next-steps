fix: register the tool in each agent scope, not only globally (0.1.11)

决定性探针（0.1.10）给出：
  registered global-ok defs=1 has=true
即：工具确实进了全局层（tools.get 全局视图能查到），但全局层里**只有我们这一个**
工具，而 Agent 能看到的 153 个工具全部来自各自作用域。也就是说，只注册全局
不足以让 Agent 看到它（全局层被限制或不被装配进工具集）。

修法：抽出 definition，除了全局注册，再监听 agent/created，把同一份定义注册进
**每个 Agent 的作用域**（WeakSet 幂等；作用域注册不受全局限制影响）。
